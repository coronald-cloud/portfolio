## Tips for Screenshots (Origins & Red Bull web work)

- **Crop out customer names, emails, and phone numbers** before sending — anything that identifies a real person
- **Full-page screenshots** are better than partial — use a browser extension like "Full Page Screen Capture" if you need the whole page
- **Dark mode vs light mode** — if your GHL is in dark mode, keep it consistent. If light mode, keep that consistent too
- For the GHL workflow map, **zoom out in the browser** (Ctrl/Cmd + minus) so more of the automation is visible in one frame

## Tips for Photography (WellFlower & Red Bull)

- If you still have cassette tapes from the Red Bull dinner, **re-photograph them** — on a dark surface, good lighting, close-up. This image will do a lot of work.
- Store renders and finished photos work best side-by-side to show the before/after — if you have both, that's a powerful moment on the page
- For event posters: if you have the original design files, export them at **2400px wide minimum** so they look sharp at large display sizes
